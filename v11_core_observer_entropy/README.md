# Cognitive Projection and Observer Entropy: A Minimal Model of Subjective Physics (v11.2.4 (technical core edition))

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.17312704.svg)](https://doi.org/10.5281/zenodo.17312704)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

This repository contains code and data for:

**Version 11.2** of the article  
**"Cognitive Projection and Observer Entropy: A Minimal Model of Subjective Physics"**

This release consolidates all prior versions (v1–v11) into a **stable, reproducible framework**.  
It establishes the **core observer entropy formalism**, implements the **thermodynamic trade-off functional**, and introduces the **multi-agent Σ-projection** as the basis of shared reality modeling.

---

### Key additions and clarifications in v11.2

- Introduction of a **formal linear stochastic model (SDE)** for observer-entropy dynamics, clarifying the mathematical meaning of the “entropy dynamics” term.  
- Inclusion of **spectral analysis** of the stochastic operator, linking stability and synchronization regimes in multi-agent systems.  
- Updated notation and reproducibility section ensuring **FAIR-compliant scientific transparency**.  
- Consolidated interpretation of observer entropy as a *formal model variable quantifying subjective indistinguishability*, distinct from macroscopic thermodynamic entropy.

The model now provides a coherent theoretical and computational foundation for the dynamics of subjective information processing and cognitive coupling.

## Quick Start

Clone the repository and run the scripts in order of model versions:

```bash
# v1: Basic entropy scaling
python von_neumann_entropy.py

# v2: Adaptive thresholds
python adaptive_perceptual_dynamics.py

# v3: Thermodynamic trade-off
python trade_off_functional_lambda_comparison.py
python landauer_extension.py

# v4: Fixed vs adaptive thresholds
python compare_entropy_fixed_adaptive.py

# v5: Reaction time coupling
python simulate_entropy_rt_full.py

# v8: Dynamic weights & Σ-projection
python dynamic_weight_feedback_enhanced.py
python cognitive_decoherence_with_sigma.py

# v10: Multi-agent shared reality
python cognitive_decoherence_with_sigma_multi_agent_system.py

# v11.2: Dynamic Observer Entropy
python simulate_entropy_dynamics.py
python generate_entropy_phase_map.py
python simulate_multiagent_synchronization.py
```

All output figures will be generated in `figures/`.

## 🧪 Full Reproduction Protocol

### 1. Install Dependencies

```bash
pip install numpy matplotlib scipy pandas tqdm
```

> **Note**: All scripts are compatible with Python ≥ 3.7.

---

### 2. Run Simulations by Component

Below is the **exact sequence** to reproduce all results. Each script corresponds to a specific section or figure in the article.

#### 🔹 **v1: Minimal Model (Sec. 2–3)**
Generates baseline entropy, norm, and trace distance plots.

```bash
python von_neumann_entropy.py
```
- Outputs:
  - `figures/entropy_vs_epsilon.pdf`
  - `figures/trace_distance_vs_epsilon.pdf`
  - `figures/norm_vs_time.pdf`

#### 🔹 **v2: Adaptive Thresholds (Sec. 3.5, Sec. 13)**
Runs adaptive dynamics based on entropy or norm feedback.

```bash
python adaptive_perceptual_dynamics.py
```
- Outputs:
  - `figures/adaptive_perceptual_dynamics.pdf`
  - `figures/adaptive_threshold_entropy.pdf`
  - `figures/adaptive_threshold_norm.pdf`
  - `figures/adaptive_entropy_entropy.pdf`
  - `figures/adaptive_norm_norm.pdf`

#### 🔹 **v3: Thermodynamic Trade-off (Sec. 9–10)**
Computes Landauer cost and optimal ε.

```bash
python landauer_extension.py
python trade_off_functional_lambda_comparison.py
```
- Outputs:
  - `figures/deltaS_vs_epsilon.pdf`
  - `figures/energy_vs_epsilon.pdf`
  - `figures/L_epsilon_lambda_comparison_plot.pdf`
  - `data/tradeoff_data_lambda*.csv`

#### 🔹 **v4: Entropy Suppression & Phase Transitions (Sec. 13)**
Compares fixed vs. adaptive thresholds.

```bash
python compare_entropy_fixed_adaptive.py
```
- Outputs:
  - `figures/entropy_comparison.pdf`
  - `figures/epsilon_over_time.pdf`
  - `figures/entropy_over_time.pdf`
  - `figures/trace_distance_over_time.pdf`

#### 🔹 **v5: Reaction Time Coupling (Sec. 7)**
Simulates entropy–RT correlation (100,000 trials).

```bash
python simulate_entropy_rt_full.py
python compare_dirichlet_params.py
```
- Outputs:
  - `figures/histogram_rt.pdf`
  - `figures/scatter_entropy_rt.pdf`
  - `figures/cdf_rt.pdf`
  - `figures/entropy_boxplot.pdf`, `rt_boxplot.pdf`, etc.
  - `data/simulated_data.csv`
  - `data/simulated_data_dirichlet_*.csv`

#### 🔹 **v6–v7: Geodesics & Retrodiction (Sec. 5.6, Extended Notes)**
Models cognitive reconstruction as boundary-value problem.

```bash
python cognitive_geodesic_simulation.py
python cognitive_geodesic_trajectories.py
python geodesic_dynamics_cognitive_action.py
python cognitive_entropy_reduction_simulation.py
python cognitive_retrodiction_simulation.py
```
- Outputs:
  - `figures/cognitive_geodesic.pdf`
  - `figures/cognitive_trajectories.pdf`
  - `figures/cognitive_action_vs_time.pdf`
  - `figures/phase_portrait.pdf`
  - `figures/potential_landscape.pdf`
  - `figures/retrodicted_states.pdf`
  - `figures/state_trajectories.pdf`

#### 🔹 **v8: Σ-Projection & Dynamic Weights (Sec. 8)**
Implements cognitive filtering and feedback-driven weight dynamics.

```bash
python cognitive_decoherence_with_sigma.py
python dynamic_weight_feedback_enhanced.py
```
- Outputs:
  - `figures/cognitive_filter_results.pdf`
  - `figures/sigma_projection_result.pdf`
  - `figures/dynamic_weight_feedback_results.pdf`
  - `figures/parameter_study.pdf`
  - `figures/geometry_effects.pdf`

#### 🔹 **v9: Phase Portraits & EEG Analogy (Extended Notes)**
Adds stochastic jumps, Tsallis entropy, and 4D visualization.

```bash
python phase_portrait.py
python plot_entropy_flux_and_jumps.py
```
- Outputs:
  - `figures/subjective_phase_portrait.pdf`
  - `figures/4d_phase_portrait.pdf`
  - `figures/entropy_flux_and_jumps_real.pdf`

#### 🔹 **v10: Multi-Agent Shared Reality (Sec. 12)**
Simulates M ≥ 2 agents and computes SRI, overlap, and convergence.

```bash
python cognitive_decoherence_with_sigma_multi_agent_system.py
```
- Outputs:
  - `figures/sri_time_series.pdf`
  - `figures/shared_overlap_matrix.pdf`
  - `figures/agent_trajectories_pca.pdf`
  - `figures/multi_agent_projection_v10.pdf`
  - `figures/parameter_study_v10.pdf`

#### 🔰 **v11.2: Dynamic Observer Entropy (Sec. 6)**
Implements evolutionary laws for observer entropy with phase diagrams and multi-agent coupling.

```bash
python simulate_entropy_dynamics.py
python generate_entropy_phase_map.py
python simulate_multiagent_synchronization.py
```
- Outputs:
  - `figures/entropy_dynamics.pdf`
  - `figures/entropy_phase_map.pdf`
  - `figures/multiagent_synchronization.pdf`
- Demonstrates synchronization/divergence regimes in multi-agent systems
